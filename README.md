# Banner Galéria

## Helyi megnyitás
Nyisd meg az `index.html` fájlt böngészőben. A képek az `images` mappában vannak.

## Ingyenes közzététel GitHub Pages segítségével
1. Hozz létre a GitHubon egy új, nyilvános repositoryt, például `banner-galeria` néven.
2. Töltsd fel a ZIP tartalmát úgy, hogy az `index.html` a repository gyökerében legyen, az `images` pedig mellette.
3. A repositoryban nyisd meg: **Settings → Pages**.
4. A Build and deployment résznél válaszd a **Deploy from a branch** lehetőséget, majd `main` és `/(root)`, végül Save.
5. Néhány perc múlva a GitHub Pages megadja a weboldalad URL-jét.

Megjegyzés: a GitHub Pages nyilvános weboldal, ezért a feltöltött képeket bárki elérheti, aki ismeri a webcímet vagy a repositoryt. Ne tölts fel bizalmas képeket.
